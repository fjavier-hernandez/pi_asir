    Erasmus Presentation — Teaching Methodology¶

    Oral talk · ≈ 4 minutes · 5 slides Francisco Javier Hernández Illán · IES Macià Abela · Crevillent Higher VET in Network Systems Administration (ASIR)

    Slide 1 — Teaching methodology with students¶

    Daily flow: from the classroom to public documentation

    • I plan the module in Aules (the official Valencian LMS, built on Moodle).
    • Lessons and tasks are linked to my official notes.
    • My notes live on GitHub and are written in Markdown.
    • They are published as a website with GitHub Pages + MkDocs Material.
    • Students get living, technical, professional documentation.

    Slide 3 — Case study · ASIR Cross-Module Project¶

    A real IT infrastructure built throughout the school year

    • PBL + CBL: Project- and Challenge-Based Learning.
    • Integration of ASIR modules (Databases, OS, Web, Networking, Security).
    • Real infrastructure deployment: Docker or AWS.
    • Continuous documentation published on GitHub Pages.
    • Cooperative work in teams of 2-3 students.

    Slide 4 — Project tools and documentation¶

    The classroom as a real systems department

    • Living documentation from day one, not in the last week.
    • Technical report published as a professional website.
    • Professional GitHub use: branches, Pull Requests, Issues, Releases.
    • Collaborative work with traceability and shared authorship.
    • DevOps skills: IaC, automation, continuous deployment.

    Real industry workflows applied from the very first day.

    Slide 5 — Using Cursor and AI in documentation¶

    AI accelerates reuse · it does not replace the teacher

    • Notes and guides already exist in Markdown.
    • Cursor helps me refactor and improve their structure.
    • I translate materials into English for Erasmus contexts.
    • I summarise long content into slide-friendly chunks.
    • I adapt documentation to multiple formats (web, slides, report).
    • Outcome: higher teaching productivity and consistent materials.
