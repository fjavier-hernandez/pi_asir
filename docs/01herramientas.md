# Herramientas del Proyecto Intermodular de ASIR

## Docker

> Docker es una herramienta clave para la **virtualización ligera mediante contenedores**, que permite desplegar servicios de forma rápida, portable y reproducible. En el contexto del **Proyecto Intermodular (PI)**, Docker facilita la integración de diferentes componentes del proyecto, asegurando entornos homogéneos y reduciendo problemas de compatibilidad.

Para profundizar en el aprendizaje de Docker, incluyendo su propuesta didáctica, criterios de evaluación y contenido práctico estructurado en sesiones, consulta la documentación completa:

**[Guía completa de Docker para el PI de ASIR →](docker.md)**

Esta guía incluye:

- Propuesta didáctica con resultados de aprendizaje
- Criterios de evaluación específicos del módulo
- Contenido estructurado en 5 bloques didácticos
- Prácticas desde conceptos básicos hasta Docker Compose
- Ejemplos reales con NGINX y Nextcloud

## Git

> Git es un **sistema de control de versiones distribuido** fundamental para el desarrollo colaborativo de proyectos. En el contexto del **Proyecto Intermodular (PI)**, Git permite el versionado del código, documentación y configuración, facilitando el trabajo en equipo y la gestión de cambios a lo largo del desarrollo del proyecto.

Para comprender en profundidad los sistemas de control de versiones, su terminología y clasificación, consulta la documentación completa:

**[Sistemas de control de versiones - Guía completa →](git.md)**

Esta guía incluye:

- Definición y clasificación de sistemas de control de versiones
- Terminología fundamental (repositorio, revisión, rama, commit, merge, etc.)
- Arquitecturas: locales, centralizados y distribuidos
- Ventajas de los sistemas distribuidos como Git
- Fundamentos teóricos para el uso profesional de Git


## GNS3

> GNS3 es un **simulador y emulador de redes** que permite diseñar, probar y documentar topologías de red complejas sin hardware físico. En el **Proyecto Intermodular (PI)**, GNS3 es crucial para experimentar con configuraciones reales, practicar el despliegue de redes y validar arquitecturas antes de la implantación final.

Para una explicación detallada sobre GNS3, su propuesta didáctica, criterios de evaluación y ejemplos de uso, consulta la siguiente guía:

**[GNS3 - Simulador de redes: guía completa →](gns3.md)**

Esta guía recoge:

- Explicación funcional de GNS3 y su arquitectura
- Resultados de aprendizaje y criterios de evaluación asociados al PI
- Contenidos prácticos estructurados en sesiones
- Casos de uso y ejemplos para practicar topologías y configuraciones

## AWS (Amazon Web Services)

> AWS es una **plataforma de servicios en la nube** que ofrece infraestructura, plataforma y aplicaciones como servicio (IaaS, PaaS, SaaS). En el **Proyecto Intermodular (PI)**, AWS permite desplegar infraestructuras escalables, aprender arquitecturas cloud modernas y prepararse para certificaciones profesionales en tecnologías cloud.

Para preparar el **Campeonato Nacional AWS GameDay 2025**, donde los equipos compiten resolviendo retos técnicos en AWS, consulta la guía completa de preparación:

**[Preparación AWS GameDay 2025 →](AWS_GameDay2025_Preparacion.md)**

Esta guía incluye:

- Resumen de conceptos clave de AWS Cloud Practitioner y AWS Architecting
- Dos prácticas guiadas paso a paso: arquitectura web de 3 capas y arquitectura serverless
- Estrategias y consejos para el día de la competición
- Recursos de estudio y glosario de términos importantes

**Sitio web oficial del campeonato:** [https://gameday2025.com](https://gameday2025.com)

## MkDocs

> MkDocs es un **generador de sitios web estáticos** que toma como entrada texto escrito en Markdown y utiliza diseños predefinidos (temas) para crear un sitio web estático. Permite modificar el aspecto del sitio, los enlaces, los datos que se muestran en la página y muchas cosas más. En el contexto del **Proyecto Intermodular (PI)**, MkDocs facilita la creación de documentación profesional y sitios web para los proyectos, permitiendo centrarse en el contenido sin preocuparse por el diseño.

Para aprender a instalar, configurar y desplegar sitios web estáticos con MkDocs y el tema Material, consulta la guía completa:

**[MkDocs - Generador de sitios web estáticos: guía completa →](mkdocs.md)**

Esta guía incluye:

- Introducción a MkDocs y conceptos básicos
- Instalación de MkDocs y Material theme
- Configuración del proyecto y archivo `mkdocs.yml`
- Despliegue en GitHub Pages
- Personalización y buenas prácticas
- Recursos y referencias

**Documentación de referencia:** Esta guía está basada en los apuntes del curso [Markdown per a la creació de recursos](https://cursos-cefire.github.io/markdown-per-a-la-creacio-de-recursos/) del CEFIRE, adaptados y traducidos al castellano.
