    Guía de Preparación - AWS GameDay 2025 (Solo Profesor)¶

    GUÍA INTERNA: Esta guía te ayuda paso a paso a preparar el Learner Lab y configurar todo lo necesario para que tus alumnos puedan realizar las prácticas de AWS GameDay 2025.

    IMPORTANTE: Información sobre el aprovisionamiento del Learner Lab¶

    Si creaste una Class con "Academy Learner Lab":

    Después de crear la Class, AWS Academy necesita aprovisionarla (prepararla) antes de que puedas acceder al Learner Lab. Este proceso puede tardar desde 30 minutos hasta varias horas.

    ¿Qué debes hacer?

    1. ⏳ Espera a recibir un correo electrónico de AWS Academy confirmando que la Class está lista
    2. 📧 El correo llegará a la dirección asociada a tu cuenta de AWS Academy
    3. ✅ Una vez que recibas el correo, podrás acceder al Learner Lab

    Mientras esperas el correo:

    • Puedes matricular a los alumnos (Paso 3)
    • Puedes preparar otro material de la práctica
    • Revisa la sección Paso 2.5 para más detalles sobre el correo de aprovisionamiento

    IMPORTANTE: Dónde encontrar el Learner Lab (después del aprovisionamiento)¶

    Una vez que hayas recibido el correo de aprovisionamiento:

    El Learner Lab NO aparece en el "Panel de control" (Dashboard principal). El Panel de control solo muestra los cursos/asignaturas, no el contenido dentro de ellos.

    Para ver el Learner Lab después del aprovisionamiento:

    1. En el menú lateral izquierdo, haz clic en "Asignaturas" o "Subjects" (icono de pila de papeles 📚)
    2. Haz clic en la Class que creaste (la que tiene "Academy Learner Lab")
    3. Una vez dentro de la Class, busca en el menú lateral o en la página principal
    4. Ahí verás el Learner Lab disponible para usar

    Resumen: - Panel de control = Lista de cursos/asignaturas - Class/Curso = Contiene el contenido (incluyendo el Learner Lab) - Learner Lab = Está dentro de la Class, no aparece como curso separado - Para verlo: Dashboard → [Selecciona Class] → [Busca Learner Lab en la Class]

    Diagnóstico: ¿Dónde está mi Learner Lab?¶

    Primero, verifica qué método usaste para crear el Learner Lab:

    ¿Qué método usaste?¶

    Opción A: Creaste una Class con "Academy Learner Lab" - ✅ Si seleccionaste "Academy Learner Lab" en el dropdown al crear una Class - El Learner Lab está dentro de esa Class - ⚠️ IMPORTANTE: La Class necesita aprovisionarse primero - Debes esperar un correo de AWS Academy confirmando que la Class está lista - Puede tardar desde 30 minutos hasta varias horas - Ve al Paso 2.5 para información sobre el correo de aprovisionamiento - Una vez que recibas el correo, ve al Paso 4 para acceder al Learner Lab

    Opción B: Creaste un curso tradicional y añadiste el Learner Lab - Si creaste un curso normal y luego añadiste el Learner Lab como contenido - El Learner Lab está dentro del contenido del curso - Sigue los pasos de diagnóstico a continuación

    Si no encuentras el Learner Lab (método B o si el método A no funciona), sigue estos pasos de diagnóstico:

    Diagnóstico 1: ¿Dónde lo creaste?¶

    1. ¿Recuerdas en qué curso lo creaste? - Anota el nombre del curso - Si no lo recuerdas, revisa todos los cursos

    2. ¿Viste un mensaje de confirmación cuando lo creaste? - Si sí: Debería estar en algún lugar del curso - Si no: Puede que no se creó correctamente

    Diagnóstico 2: Verificar curso por curso¶

    1. Ve a "Asignaturas" en el menú lateral
    2. Haz clic en el primer curso de la lista
    3. Dentro del curso, busca en: - Menú lateral: "Módulos", "Contenidos", "Inicio" - Pestañas superiores: "Módulos", "Content"
    4. Busca cualquier referencia a: - "Learner Lab" - "Lab" - "AWS" - "Lanzamiento del laboratorio"
    5. Si no está en este curso, repite con el siguiente curso

    Diagnóstico 3: Buscar en toda la página del curso¶

    1. Dentro de cualquier curso, presiona Ctrl+F (o Cmd+F en Mac)
    2. Busca estas palabras: - "Learner" - "Lab" - "AWS" - "Laboratorio"
    3. Esto buscará en toda la página del curso

    Diagnóstico 4: Verificar si realmente se creó¶

    Si después de buscar en todos los cursos no encuentras nada:

    1. Es posible que no se creó correctamente
    2. Ve al Paso 4 de esta guía y crea el Learner Lab de nuevo
    3. Esta vez, anota exactamente: - En qué curso lo creas - Qué mensaje aparece al crearlo - Dónde aparece después de crearlo

    Paso 1: Acceder a AWS Academy¶

    Objetivo: Iniciar sesión en AWS Academy como instructor.

    1.1. Acceder a la plataforma¶

    1. Abre un navegador web
    2. Ve a: https://awsacademy.instructure.com/login/canvas
    3. Inicia sesión con tus credenciales de instructor de AWS Academy - Si no tienes cuenta, contacta con tu coordinador o administrador - Si olvidaste la contraseña, usa la opción "Forgot password"

    1.2. Verificar acceso¶

    Una vez dentro de AWS Academy:

    1. Verifica que puedes ver el Dashboard principal
    2. Verifica que apareces como Instructor o Teacher
    3. Deberías ver opciones como: - Contenidos / Content - Personas / People - Módulos / Modules

    Primera vez

    Si es tu primera vez accediendo, puede que necesites completar un perfil o configurar algunas preferencias.

    Paso 2: Crear una Class con Learner Lab (MÉTODO RECOMENDADO)¶

    Objetivo: Crear una Class (clase) directamente con el "Academy Learner Lab" para que los alumnos accedan directamente.

    Método más directo

    Este es el método más simple: crear una Class directamente con el curso "Academy Learner Lab". La Class ya incluye el Learner Lab automáticamente, no necesitas añadirlo después.

    2.1. Acceder a la creación de Class¶

    1. En el Dashboard de AWS Academy, busca el botón "Create a Class" o "Crear una clase" - Puede estar en la parte superior derecha - O en el menú lateral izquierdo - O en una sección destacada del Dashboard

    2. Haz clic en "Create a Class"

    2.2. Configurar la Class¶

    Se abrirá un formulario con dos columnas. Completa los campos:

    Columna izquierda - Detalles del curso:

    1. Course (Curso): - Haz clic en el dropdown - Busca y selecciona "Academy Learner Lab" (debería estar en la lista) - ✅ Esta es la opción que necesitas para acceder al Learner Lab

    2. Start Date (Fecha de inicio): - Selecciona la fecha de inicio de la clase

    3. End Date (Fecha de fin): - Selecciona la fecha de fin de la clase - Importante: La duración debe ser adecuada (normalmente hay un mínimo)

    4. Time Zone (Zona horaria): - Selecciona tu zona horaria

    5. Language (Idioma): - Selecciona el idioma (normalmente "English" o "Español")

    6. Delivery Modality (Modalidad de entrega): - Selecciona la modalidad (Online, Presencial, Híbrido, etc.) - Nota: Esto es solo para reportes, no afecta el funcionamiento

    Columna derecha - Configuración de la clase:

    1. Course Nickname (Apodo del curso): (Opcional) - Puedes poner un nombre como "AWS GameDay 2025 - Preparación" - Este nombre solo lo ves tú, no los alumnos

    2. Start Time (Hora de inicio): - Selecciona la hora de inicio (por defecto puede aparecer "08:00 AM")

    3. End Time (Hora de fin): - Selecciona la hora de fin (por defecto puede aparecer "06:00 PM")

    4. Otros campos: (si aparecen) - Completa según sea necesario

    2.3. Aceptar términos y crear¶

    1. Lee el Acceptable Use Policy (Política de uso aceptable) en la parte inferior
    2. Haz clic en el botón "Submit" (Enviar) en la parte inferior derecha
    3. Espera a que se cree la Class (puede tomar unos segundos)

    2.4. Verificar que la Class se creó¶

    1. Después de hacer clic en "Submit", deberías ver un mensaje de confirmación
    2. Puede que te redirijan automáticamente, o puede que vuelvas al Dashboard
    3. Anota el nombre de la Class para referencia futura

    IMPORTANTE: La Class necesita aprovisionarse

    Después de crear la Class, AWS Academy necesita aprovisionarla (prepararla) antes de que puedas usarla. Este proceso puede tardar desde unos minutos hasta varias horas.

    ¿Qué significa esto? - La Class aparece en tu lista, pero el Learner Lab aún no está disponible - AWS Academy te enviará un correo electrónico cuando la Class esté lista - No podrás acceder al Learner Lab hasta que recibas ese correo

    Mientras tanto: - La Class puede aparecer en tu Dashboard, pero puede estar en estado "Pendiente" o "Aprovisionando" - Es normal que aún no puedas acceder al Learner Lab - Solo necesitas esperar a recibir el correo de confirmación

    Paso 2.5: Esperar el correo de aprovisionamiento¶

    Objetivo: Entender qué correo debes esperar y qué hacer cuando llegue.

    2.5.1. El correo de aprovisionamiento¶

    ¿Qué correo debes esperar?

    AWS Academy te enviará un correo electrónico a la dirección con la que te registraste cuando la Class esté completamente aprovisionada y lista para usar.

    El correo típicamente contiene:

    1. Asunto: Algo como: - "Your AWS Academy class is ready" - "Class [nombre] is now available" - "AWS Academy Class Provisioning Complete" - O similar en español si está en ese idioma

    2. Contenido: El correo normalmente incluye: - Confirmación de que la Class está lista - Nombre de la Class - Instrucciones para acceder - Enlaces directos a la Class

    2.5.2. ¿Cuánto tiempo puede tardar?¶

    Tiempo típico de aprovisionamiento:

    • Mínimo: 5-15 minutos (en casos rápidos)
    • Típico: 30 minutos - 2 horas
    • Máximo: Puede tardar hasta 24 horas en casos excepcionales

    Factores que pueden afectar el tiempo

    El tiempo de aprovisionamiento puede variar según: - La carga del sistema de AWS Academy en ese momento - El tipo de Class (Learner Lab suele ser rápido) - Si es la primera Class que creas en tu cuenta - Hora del día (puede haber más tráfico en horas punta)

    2.5.3. Qué hacer mientras esperas¶

    Mientras esperas el correo:

    1. Verifica tu correo regularmente: - Revisa la bandeja de entrada - Revisa la carpeta de spam/correo no deseado - El correo puede llegar a la dirección asociada a tu cuenta de AWS Academy

    2. Puedes verificar el estado en AWS Academy: - Entra a AWS Academy Dashboard - Busca tu Class en la lista - Puede mostrar estado como "Aprovisionando", "Pendiente", o "Activa" - Si está "Activa", intenta acceder aunque no hayas recibido el correo

    3. Prepara otras cosas mientras tanto: - Puedes matricular a los alumnos (Paso 3) - Puedes revisar el contenido de la guía de prácticas - Puedes preparar material adicional

    2.5.4. Cuando llegue el correo¶

    Una vez que recibas el correo:

    1. Abre el correo y léelo completamente
    2. Haz clic en el enlace que te proporciona (si hay uno) para acceder a la Class
    3. O simplemente ve al Dashboard de AWS Academy y entra a tu Class
    4. Continúa con el Paso 4 de esta guía para acceder al Learner Lab

    Si no recibes el correo después de 24 horas

    Si después de 24 horas no has recibido el correo:

    1. Verifica tu carpeta de spam/correo no deseado
    2. Verifica el correo correcto: Asegúrate de que estás revisando el correo asociado a tu cuenta de AWS Academy
    3. Verifica el estado de la Class: Entra a AWS Academy y comprueba si la Class está "Activa" (puede estar lista aunque no llegue el correo)
    4. Contacta con soporte: Si la Class no está activa después de 24 horas, contacta con el administrador de AWS Academy o con soporte técnico

    ¿Dónde encontrar la Class creada?

    La Class que acabas de crear aparecerá en tu Dashboard como una clase/asignatura. Al hacer clic en ella, tendrás acceso directo al Learner Lab.

    Paso 2 (Alternativo): Crear o seleccionar un curso tradicional¶

    Objetivo: Si prefieres el método tradicional, crear un curso y añadir el Learner Lab después.

    Método alternativo

    Este método es más complejo. Si ya creaste una Class con "Academy Learner Lab" en el Paso 2 anterior, NO necesitas este paso. Este método es para si prefieres tener un curso personalizado con más contenido además del Learner Lab.

    2.1. Si ya tienes un curso creado¶

    1. En el Dashboard, busca el curso donde quieres añadir las prácticas
    2. Haz clic en el curso para acceder a él
    3. Continúa con el Paso 4 (añadir Learner Lab al curso)

    2.2. Si necesitas crear un nuevo curso¶

    1. En el Dashboard, busca la opción "Crear curso" o "Create Course"
    2. Completa la información básica: - Nombre del curso: Ej: "AWS GameDay 2025 - Preparación" - Descripción: Breve explicación de los objetivos, contenidos y resultados de aprendizaje del curso - Configuración del curso: Sigue el asistente
    3. Una vez creado, accede al curso
    4. Continúa con el Paso 4 para añadir el Learner Lab

    Paso 3: Matricular a los alumnos¶

    Objetivo: Añadir a los alumnos a la Class/curso para que puedan acceder al Learner Lab.

    Importante

    Si creaste una Class con "Academy Learner Lab" (Paso 2), los alumnos se matriculan directamente en esa Class. Si creaste un curso tradicional, los alumnos se matriculan en ese curso.

    3.1. Acceder a la gestión de personas¶

    1. Si creaste una Class (método recomendado): - Accede a la Class desde el Dashboard - Dentro de la Class, busca la opción "Personas" o "People" en el menú lateral - Haz clic en "Personas"

    2. Si creaste un curso tradicional: - Accede al curso desde el Dashboard - Dentro del curso, busca la opción "Personas" o "People" en el menú lateral - Haz clic en "Personas"

    3.2. Añadir estudiantes¶

    1. Haz clic en el botón "+ Personas" o "+ People"
    2. Selecciona una de estas opciones:

    Opción A - Añadir por email: - Ingresa los emails de los alumnos (uno por línea o separados por comas) - Selecciona el rol: "Estudiante" o "Student" - Haz clic en "Enviar invitaciones" o "Send invitations"

    Opción B - Importar desde archivo: - Si tienes una lista en CSV o Excel, usa la opción de importar - Formato típico: Email, Nombre, Apellido - Selecciona el rol para todos: "Estudiante"

    3.3. Verificar matriculación¶

    1. Una vez añadidos, verifica que todos aparecen en la lista de "Personas"
    2. Verifica que su estado es "Activo" o "Active"
    3. Los alumnos recibirán un email de invitación al curso

    Importante

    Los alumnos necesitan aceptar la invitación por email antes de poder acceder al curso.

    Paso 4: Acceder al Learner Lab (Si creaste una Class con "Academy Learner Lab")¶

    Objetivo: Verificar y acceder al Learner Lab que ya está incluido en la Class.

    IMPORTANTE - Lee esto primero

    Antes de intentar acceder al Learner Lab, asegúrate de:

    1. ✅ Has recibido el correo de aprovisionamiento de AWS Academy confirmando que la Class está lista - Si NO has recibido el correo, vuelve al Paso 2.5 y espera a recibirlo - La Class necesita estar completamente aprovisionada antes de poder acceder al Learner Lab

    2. ✅ La Class está en estado "Activa" en tu Dashboard

    Si creaste una Class con "Academy Learner Lab" en el Paso 2 y ya recibiste el correo de confirmación, el Learner Lab YA ESTÁ INCLUIDO automáticamente. No necesitas añadirlo manualmente.

    Si aún NO has recibido el correo: - Es normal, el aprovisionamiento puede tardar de 30 minutos a varias horas - Revisa el Paso 2.5 para más información sobre qué esperar - Mientras tanto, puedes matricular a los alumnos (Paso 3)

    4.1. Acceder a la Class¶

    1. En el Dashboard de AWS Academy, busca la Class que creaste - Debería aparecer en la lista de clases/cursos - Puede tener el nombre que le pusiste o el nombre "Academy Learner Lab" - O el "Course Nickname" que configuraste al crearla

    2. Haz clic en la Class para entrar

    Cómo identificar tu Class

    Si creaste la Class recientemente, debería aparecer cerca del principio de la lista en el Dashboard. Busca: - El nombre/apodo que le pusiste al crearla - Una Class con fecha de inicio reciente - O simplemente busca cualquier Class nueva que aparezca en tu lista

    4.2. Buscar el Learner Lab dentro de la Class¶

    Una vez dentro de la Class, el Learner Lab debería estar disponible directamente. Sigue estos pasos:

    Paso 1: Revisar el menú lateral izquierdo

    1. En el menú lateral izquierdo de la Class, busca opciones como: - "Learner Lab" o "Laboratorio" ← Busca primero esto - "AWS" - "Dashboard" o "Panel" - "Lab" o "Laboratorio"

    2. Si ves alguna de estas opciones, haz clic en ella

    Paso 2: Si no está en el menú lateral, revisar la página principal

    1. Si estás en la página de inicio de la Class, desplázate por la página
    2. Busca: - Enlaces o botones que digan "Learner Lab", "AWS Lab", o "Start Lab" - Una sección dedicada al laboratorio (puede tener un icono de AWS) - Tarjetas o bloques con información sobre el Learner Lab

    Paso 3: Buscar en Módulos/Contenidos

    Si no lo encuentras en los pasos anteriores:

    1. En el menú lateral izquierdo, busca la opción: - "Módulos" o "Modules" - "Contenidos" o "Content" - "Inicio" o "Home" (y luego buscar contenido)

    2. Haz clic en esa opción

    3. Busca en la lista de contenido: - Un elemento que diga "Learner Lab" - Un enlace o botón relacionado con AWS - Un módulo que contenga el laboratorio

    Paso 4: Buscar en toda la Class (método exhaustivo)

    1. Presiona Ctrl+F (o Cmd+F en Mac) para buscar en toda la página
    2. Busca estas palabras: - "Learner" - "Lab" - "AWS" - "Laboratorio"
    3. Esto te mostrará todas las referencias al Learner Lab en la página

    4.3. Verificar que puedes acceder al Learner Lab¶

    Una vez que encuentres el Learner Lab:

    1. Haz clic en el Learner Lab (puede ser un enlace, botón, o elemento en un módulo)

    2. Deberías ver una interfaz del Learner Lab con información como: - "Start Lab" (Iniciar laboratorio) o botón similar - Créditos disponibles (ej: "$100 USD") - Información sobre el tiempo disponible del lab - Opción para acceder al AWS Console o Dashboard de AWS - Información sobre cuándo expira el lab

    3. Verifica que todo se ve correcto antes de iniciar el lab

    Qué ver cuando accedas al Learner Lab

    La interfaz del Learner Lab típicamente muestra: - Un botón grande para "Start Lab" o "Iniciar Laboratorio" - La cantidad de créditos disponibles (normalmente $100 USD) - Información sobre el tiempo restante del lab (cuando esté iniciado) - Un botón o enlace para acceder a la AWS Management Console - Instrucciones sobre cómo usar el lab

    Si no encuentras el Learner Lab en la Class

    Si después de buscar en todos los lugares mencionados no encuentras el Learner Lab:

    1. Espera unos minutos: A veces el Learner Lab tarda unos minutos en aparecer después de crear la Class
    2. Refresca la página: Presiona F5 o Ctrl+R para refrescar
    3. Verifica que seleccionaste el curso correcto: Asegúrate de que realmente seleccionaste "Academy Learner Lab" en el dropdown cuando creaste la Class
    4. Revisa todas las secciones: Ve a cada opción del menú lateral de la Class (Inicio, Módulos, Asignaciones, etc.)
    5. Contacta con soporte: Si después de todo esto no aparece, puede haber un problema con la Class y necesitas contactar con el administrador de AWS Academy

    Paso 4 (Alternativo): Crear el Learner Lab en un curso tradicional¶

    Objetivo: Añadir el Learner Lab manualmente a un curso tradicional (si no usaste el método de Class).

    Solo si usaste método alternativo

    Este paso solo es necesario si creaste un curso tradicional en el Paso 2 (alternativo). Si ya creaste una Class con "Academy Learner Lab", el Learner Lab ya está incluido y puedes saltarte este paso.

    4.1. Verificar que tienes un curso creado¶

    Primero verifica que tienes un curso:

    1. Haz clic en "Asignaturas" o "Subjects" en el menú lateral izquierdo
    2. Deberías ver una lista de cursos/asignaturas

    Si NO tienes ningún curso:

    1. Ve al Paso 2 de esta guía para crear un curso primero
    2. O usa un curso existente si ya tienes uno

    Si tienes cursos pero no sabes cuál usar:

    1. Puedes usar cualquier curso existente
    2. O crear uno nuevo específico para estas prácticas
    3. Anota el nombre del curso que vas a usar

    4.2. Entrar al curso¶

    1. En la lista de "Asignaturas", haz clic en el curso donde quieres crear el Learner Lab
    2. Esto te llevará dentro del curso (la interfaz cambiará)
    3. Deberías ver: - Un menú lateral con opciones del curso (Inicio, Módulos, Asignaciones, etc.) - O pestañas en la parte superior - El nombre del curso en algún lugar visible

    4.3. Acceder a Contenidos del curso - GUÍA DETALLADA¶

    Una vez dentro del curso, busca dónde está el contenido. Puede estar en diferentes lugares:

    Método 1: Buscar en el menú lateral izquierdo del curso

    Cuando entras a un curso, en el menú lateral izquierdo deberías ver opciones como: - "Inicio" o "Home" - "Anuncios" o "Announcements" - "Asignaciones" o "Assignments" - "Módulos" o "Modules" ← Empieza aquí - "Páginas" o "Pages" - "Discusiones" o "Discussions" - "Calificaciones" o "Grades"

    Paso a paso: 1. Haz clic en "Módulos" o "Modules" en el menú lateral 2. Deberías ver una lista de módulos o contenido del curso 3. Si ya creaste el Learner Lab, debería aparecer ahí

    Método 2: Buscar en pestañas superiores

    1. Mira en la parte superior de la página del curso
    2. Busca pestañas como: "Módulos", "Contenidos", "Modules", "Content"
    3. Haz clic en la pestaña "Módulos"

    Método 3: Buscar en la página principal del curso

    1. Si estás en "Inicio" o "Home" del curso
    2. Desplázate por la página principal
    3. Busca elementos o enlaces que digan "Lab", "AWS" o contenido relacionado

    Qué buscar

    El Learner Lab puede aparecer como: - Un enlace/icono que dice "Learner Lab" - Un elemento que dice "Lanzamiento del laboratorio para alumnado" - Un elemento con icono de AWS o de laboratorio - Un elemento en un módulo específico**

    4.4. Añadir el Learner Lab - PASOS ESPECÍFICOS¶

    IMPORTANTE: Si no encuentras el Learner Lab que creaste, puedes crearlo de nuevo siguiendo estos pasos.

    Una vez que estés en la sección "Módulos" o "Contenidos" del curso:

    Paso 1: Buscar el botón para añadir contenido

    Busca el botón "+" o "Add" o "Agregar" o "Añadir": - Puede estar en la parte superior derecha de la página - O puede estar dentro de un módulo específico (si ya tienes módulos creados) - O puede ser un botón que dice "Añadir elemento" o "Add Item"

    Paso 2: Si hay módulos, añadir a un módulo o crear uno nuevo

    Si ya tienes módulos: 1. Haz clic en un módulo existente para abrirlo 2. Busca el botón "+" dentro del módulo 3. O crea un nuevo módulo haciendo clic en "+ Módulo" o "+ Module"

    Si no tienes módulos: 1. Crea un módulo nuevo (por ejemplo, "Prácticas AWS GameDay") 2. Haz clic en "+ Módulo" o "+ Module" 3. Dale un nombre al módulo 4. Guarda el módulo

    Paso 3: Añadir el Learner Lab

    1. Haz clic en el botón "+" (puede estar dentro de un módulo o en la barra superior)
    2. Se abrirá un menú desplegable o una lista de opciones
    3. Busca estas opciones en el menú: - "Lanzamiento del laboratorio para alumnado" - "Learner Lab" - "AWS Academy Learner Lab" - "External Tool" o "Herramienta Externa" (y luego buscar AWS) - "LTI Tool" o "Herramienta LTI" (y luego buscar AWS)

    Si no ves ninguna de estas opciones:

    1. Busca en el menú "Más herramientas" o "More tools"
    2. O busca "AWS" en el buscador de herramientas (si hay uno)
    3. O busca "External Tool" y luego dentro de esa opción busca AWS

    Método 2: Si no ves la opción directamente

    1. En el menú de añadir contenido, busca: - "External Tool" o "Herramienta Externa" - "LTI Tool" o "Herramienta LTI" - "AWS" en la lista de herramientas externas

    2. Si ves una lista de herramientas, busca "AWS Academy Learner Lab" o similar

    Método 3: Añadir desde un módulo

    1. Si tienes módulos creados, haz clic en el módulo donde quieres añadir el lab
    2. Dentro del módulo, busca el botón "+" o "Add Item"
    3. Busca las mismas opciones mencionadas arriba

    4.5. Configurar el Learner Lab¶

    Una vez que selecciones la opción de Learner Lab, se abrirá un formulario:

    Configuración básica:

    1. Nombre o URL: - Puede pedirte un nombre: Ej: "Learner Lab - Prácticas AWS GameDay 2025" - O puede pedirte una URL (normalmente ya viene preconfigurada para Learner Lab)

    2. Descripción: (Opcional) - Puedes añadir una descripción de lo que van a hacer los alumnos

    3. Opciones adicionales: - Puede haber opciones de visibilidad (visible para estudiantes o no) - Puede haber opciones de fechas de disponibilidad - Deja las opciones por defecto si no estás seguro

    4. Guardar: - Haz clic en "Agregar", "Añadir", "Add", "Guardar" o "Save"

    Después de guardar:

    1. Deberías ver un mensaje de confirmación
    2. El Learner Lab debería aparecer en la lista de contenido del módulo o curso
    3. Anota exactamente dónde aparece para encontrarlo después

    IMPORTANTE: Anotar dónde lo creaste

    Después de crear el Learner Lab: 1. Anota: ¿En qué curso lo creaste? (nombre del curso) 2. Anota: ¿En qué módulo está? (nombre del módulo) 3. Anota: ¿Qué mensaje de confirmación viste? 4. Toma una captura de pantalla de dónde aparece para referencia futura

    Si no encuentras la opción de Learner Lab

    Posibles causas:

    1. El Learner Lab no está habilitado en tu cuenta: - Necesitas permisos de instructor con acceso a Learner Labs - Contacta con el administrador de AWS Academy

    2. Estás buscando en el lugar incorrecto: - El Learner Lab se añade como contenido dentro de un curso - Debe estar dentro de un módulo o en la lista de contenidos

    3. El curso no está configurado correctamente: - Verifica que el curso esté publicado/activado - Algunos cursos pueden tener restricciones

    Qué hacer: - Intenta buscar "External Tool" o "AWS" en las opciones de añadir contenido - Si no aparece ninguna opción relacionada con AWS, contacta con el administrador - Verifica que tu cuenta de instructor tiene permisos para crear Learner Labs

    4.5. Verificar que el Learner Lab se creó correctamente¶

    Después de crear el Learner Lab:

    1. Deberías ver un nuevo elemento en la lista de contenidos del curso
    2. Puede aparecer con un nombre como "Learner Lab" o el nombre que le diste
    3. Puede tener un icono relacionado con AWS o laboratorios

    Si no lo ves:

    1. Refresca la página (F5 o Ctrl+R)
    2. Verifica que estás en la sección correcta: - Asegúrate de estar en "Contenidos", "Módulos" o la sección principal del curso - No estés en subsecciones como "Asignaciones" o "Anuncios"
    3. Busca en diferentes módulos: Si tienes varios módulos, verifica en cada uno

    4.6. Dónde encontrar el Learner Lab después de crearlo¶

    IMPORTANTE: El Learner Lab NO aparece en el "Panel de control". Está dentro del contenido de un curso.

    Pasos para encontrarlo:

    1. Ve a "Asignaturas" en el menú lateral izquierdo
    2. Haz clic en el curso donde creaste el Learner Lab
    3. Busca en el menú del curso: - Opción "Contenidos" o "Content" - O pestaña "Módulos" o "Modules" - O pestaña "Inicio" (y luego buscar en el contenido)
    4. El Learner Lab estará listado ahí como un elemento del contenido

    Si todavía no lo encuentras:

    1. Verifica que realmente se creó: - ¿Viste un mensaje de confirmación al crearlo? - ¿Apareció algo nuevo en la lista?
    2. Busca en todas las secciones del curso: - Revisa "Módulos" - Revisa "Contenidos"
      - Revisa "Páginas" - Revisa "Asignaciones" (a veces puede estar ahí)
    3. Busca por nombre: - Si le pusiste un nombre específico, busca ese nombre en la página del curso - Usa Ctrl+F para buscar en la página

    Verificación paso a paso

    Si después de seguir estos pasos no encuentras el Learner Lab, es posible que: - No se creó correctamente (intenta crearlo de nuevo) - Está en un módulo que no has revisado - Necesitas permisos adicionales (contacta con administrador)

    Paso 5: Probar el Learner Lab (Como Estudiante de Prueba)¶

    Objetivo: Verificar que el Learner Lab funciona correctamente antes de que los alumnos lo usen.

    Tanto para Class como para curso tradicional

    Este paso funciona igual independientemente de si creaste una Class con "Academy Learner Lab" o un curso tradicional con Learner Lab añadido.

    5.1. Cambiar a vista de estudiante¶

    1. En la esquina superior derecha de AWS Academy, busca el botón "Ver como estudiante" o "View as Student"
    2. Haz clic en el botón
    3. Aparecerá una barra rosa en la parte inferior indicando que estás en vista de estudiante

    Vista de estudiante

    Esta opción te permite ver exactamente lo que ven los alumnos y usar el Learner Lab con los mismos permisos.

    5.2. Acceder al Learner Lab como estudiante¶

    1. En vista de estudiante, ve a "Contenidos"
    2. Busca el Learner Lab que acabas de crear
    3. Haz clic en el Learner Lab

    5.3. Iniciar el Learner Lab¶

    1. Verás una pantalla con información del Learner Lab
    2. Busca el botón "Start Lab" o "Iniciar Laboratorio"
    3. Haz clic en "Start Lab"
    4. Aparecerá una confirmación → Haz clic en "Yes" o "Sí"
    5. ESPERA 1-2 minutos mientras se inicia el lab
    6. Verás un mensaje indicando que el lab está iniciado

    Tiempo del lab

    El Learner Lab tiene un tiempo limitado (normalmente 4 horas). El tiempo comienza a contar desde que inicias el lab.

    5.4. Acceder a la consola de AWS¶

    1. Una vez iniciado el lab, busca el botón "AWS" o "Workarea" (área de trabajo)
    2. Haz clic en "AWS" o "Workarea"
    3. Se abrirá una nueva pestaña con la consola de AWS
    4. Verifica que el LED al lado de "AWS" está en verde, indicando que el lab está activo

    5.5. Verificar acceso a servicios AWS¶

    1. En la consola de AWS, busca el servicio "EC2" en la barra de búsqueda superior
    2. Haz clic en EC2
    3. Verifica que puedes ver la página de EC2 sin errores
    4. Repite con "VPC" para verificar acceso a networking
    5. Verifica que puedes ver la región (normalmente aparece en la esquina superior derecha, ej: us-east-1)

    Verificación completa

    Si puedes acceder a EC2 y VPC sin problemas, el Learner Lab está funcionando correctamente.

    5.6. Finalizar el lab de prueba¶

    1. Vuelve a la pestaña del Learner Lab
    2. Haz clic en "End Lab" o "Finalizar Laboratorio"
    3. Confirma la acción
    4. Esto eliminará todos los recursos creados (si creaste alguno)

    5.7. Volver a vista de instructor¶

    1. En la barra rosa inferior, haz clic en "Abandona la vista de estudiante" o "Leave Student View"
    2. Volverás a tu vista de instructor

    Prueba recomendada

    Es buena idea realizar una prueba rápida creando un recurso simple (como una instancia EC2) para verificar que todo funciona correctamente antes de la sesión con alumnos.

    Cada Learner Lab proporciona $100 USD de crédito. Verifica:

    1. Accede al Learner Lab como estudiante de prueba
    2. Inicia el lab
    3. En la información del lab, deberías ver información sobre el crédito disponible
    4. Normalmente cada estudiante tiene $100 USD para todo el curso

    Importante sobre créditos

    • Los créditos son por estudiante, no compartidos
    • Si un estudiante usa todos sus créditos, no puede crear más recursos
    • Enfatiza a los alumnos que usen recursos del Free Tier cuando sea posible
    • Recuerda que deben eliminar recursos cuando terminen

    2. Security Groups: - Qué son y para qué sirven - Cómo funcionan (stateful) - Diferencia con firewalls tradicionales

    3. NAT Gateway: - Por qué está en subnet pública - Para qué sirve - Coste asociado

    4. Load Balancer: - Qué es y para qué sirve - Alta disponibilidad

    5. Lambda y serverless: - Concepto de serverless - Ventajas y desventajas

    • Subnets en diferentes AZs
    • Security Groups configurados
    • Instancias EC2 funcionando
    • Load Balancer distribuyendo tráfico
    • RDS accesible desde EC2

    8.4. Preparar solución de problemas comunes¶

    Prepara respuestas para estos problemas frecuentes:

    "No puedo acceder a la consola de AWS": - Verificar que el lab está iniciado (LED verde) - Verificar que no hay bloqueadores de ventanas emergentes - Intentar hacer clic en "AWS" o "Workarea" de nuevo

    "Se me acabó el tiempo del lab": - Pueden finalizar y reiniciar el lab - Advertir que se eliminan todos los recursos

    "No puedo crear recursos": - Verificar que el lab está activo - Verificar créditos disponibles - Verificar que están en la región correcta

    10.1. El Learner Lab no está en el Panel de control¶

    El Panel de control solo muestra los cursos/asignaturas, no el contenido dentro de ellos.

    10.2. Cómo acceder al Learner Lab que creaste¶

    2. Verás una lista de todos tus cursos/asignaturas
    3. Haz clic en el curso donde creaste el Learner Lab
    4. Una vez dentro del curso, verás diferentes secciones: - "Contenidos" o "Content" o "Módulos" o "Modules"
    5. Haz clic en "Contenidos"
    6. Ahí verás el Learner Lab que creaste como un elemento del contenido

    Método 2: Desde la URL directa del curso

    1. Si ya sabes la URL del curso, accede directamente
    2. Una vez en el curso, ve a "Contenidos"

    10.3. Verificar que el Learner Lab es accesible¶

    1. Una vez que encuentres el Learner Lab en el contenido del curso
    2. Haz clic en él para verificar que se abre
    3. Deberías ver la interfaz del Learner Lab con opciones como: - Botón para iniciar el lab - Información sobre créditos disponibles - Estado del lab

    Resumen

    • Panel de control = Lista de cursos/asignaturas
    • Curso/Asignatura = Contiene contenido (módulos, lecciones, labs)
    • Learner Lab = Contenido dentro de un curso

    2. Dentro del curso, ve a "Contenidos"
    3. Busca el elemento "Lanzamiento del laboratorio para alumnado..." o "Learner Lab"
    4. Haz clic en él para abrirlo
    5. Una vez dentro del Learner Lab, busca la pestaña "Dashboard" o "Panel" o "Controls"
    6. Haz clic en "Dashboard"

    11.2. Entender el Dashboard del Learner Lab¶

    El Dashboard muestra:

    • Lista de estudiantes: Todos los alumnos matriculados en el curso
    • Estado del lab:
    • LED verde = Lab iniciado y activo
    • LED gris = Lab no iniciado
    • Controles: Puedes iniciar/detener labs de estudiantes

    Cuándo verás estudiantes en el Dashboard

    • Solo verás los labs de estudiantes que ya han iniciado su lab al menos una vez
    • Si un estudiante nunca ha iniciado el lab, puede que no aparezca en el Dashboard
    • Puedes iniciar el lab por ellos desde aquí

    11.3. Usar el Dashboard durante la práctica¶

    Durante la sesión:

    1. Accede al Dashboard del Learner Lab (desde el curso → Contenidos → Learner Lab → Dashboard)

    3. Puedes ayudar a iniciar el lab si algún alumno tiene problemas
    4. Puedes acceder al lab de un estudiante para ayudarle: - Haz clic en el nombre del estudiante - Haz clic en "Workarea" o "AWS" para ver su consola de AWS

    Ayuda a estudiantes

    Si un alumno tiene problemas, puedes acceder a su lab desde el Dashboard para ver qué está pasando y ayudarle.

    Objetivo: Verificar que todo está listo antes de que los alumnos comiencen.

    Pruebas realizadas: - [ ] Accedido al Learner Lab como estudiante de prueba - [ ] Iniciado el lab exitosamente - [ ] Accedido a la consola de AWS - [ ] Verificado acceso a servicios (EC2, VPC) - [ ] (Opcional) Realizada práctica completa de prueba

    Paso 14: Durante la sesión - Guía rápida¶

    Objetivo: Tener una referencia rápida de qué hacer durante la sesión práctica.

    Al inicio de la sesión¶

    1. Presentación (5 minutos): - Explicar qué van a hacer - Mostrar diagrama de arquitectura - Explicar el Learner Lab y créditos disponibles

    2. Acceso al Learner Lab (10 minutos): - Guiar a los alumnos para acceder a AWS Academy - Ayudarles a iniciar el Learner Lab - Verificar que todos pueden acceder a la consola de AWS

    3. Verificación inicial (5 minutos): - Verificar que todos tienen el lab iniciado (usando Dashboard) - Verificar que pueden acceder a EC2 y VPC - Resolver problemas de acceso si los hay

    Durante la práctica¶

    1. Explicar paso a paso: - Explica cada paso antes de que lo hagan - Muestra el diagrama/arquitectura mientras explicas - Haz pausas para verificar que todos van al mismo ritmo

    2. Verificaciones periódicas: - Cada 15-20 minutos, verifica el progreso - Usa el Dashboard para ver quién tiene problemas - Responde preguntas individuales

    3. Gestión de problemas: - Si muchos alumnos tienen el mismo problema, para y explica la solución a todos - Si un alumno tiene problemas únicos, ayúdale individualmente (puedes acceder a su lab desde el Dashboard)

    4. Puntos de control: - Después de crear VPC y subnets → Verificar - Después de crear Security Groups → Verificar - Después de crear EC2 → Verificar que funcionan - Después de crear ALB → Verificar distribución de carga

    Al final de la sesión¶

    1. Verificación final: - Verificar que la arquitectura funciona - Probar que el ALB distribuye tráfico - Verificar que pueden conectarse a RDS

    2. Limpieza: - Recordar a los alumnos que deben eliminar recursos - Explicar cómo eliminar recursos (en orden) - Verificar que eliminan recursos críticos (NAT Gateway, Load Balancer)

    3. Cierre: - Resumir lo aprendido - Aclarar dudas finales - Recordar sobre el tiempo del lab (si no terminaron, pueden continuar en otro momento)

    Paso 15: Acceder al lab de un estudiante para ayudarle¶

    Objetivo: Saber cómo acceder al lab de un estudiante específico para ayudarle con problemas.

    15.1. Acceder al Dashboard del Learner Lab¶

    1. Primero accede al curso: Ve a "Asignaturas" → Selecciona el curso donde está el Learner Lab
    2. Dentro del curso, ve a "Contenidos"
    3. Haz clic en el Learner Lab que creaste
    4. Busca y haz clic en la pestaña "Dashboard" o "Panel"
    5. Verás una lista de estudiantes con el estado de sus labs

    15.2. Encontrar un estudiante específico¶

    1. En el Dashboard, busca el nombre del estudiante en la lista
    2. Verifica el estado de su lab: - LED verde: Lab iniciado y activo - LED gris: Lab no iniciado

    15.3. Si el lab está iniciado¶

    1. Haz clic en el nombre del estudiante o en "Workarea" o "AWS"
    2. Se abrirá la consola de AWS del estudiante
    3. Puedes ver todos sus recursos y configuraciones
    4. Puedes ayudarle a identificar problemas

    15.4. Si el lab no está iniciado¶

    1. Haz clic en "Controls" o en los tres puntos (...) junto al nombre del estudiante
    2. Selecciona "Start Lab" o "Iniciar Laboratorio"
    3. Espera a que se inicie (1-2 minutos)
    4. El LED cambiará a verde cuando esté listo
    5. Luego haz clic en "Workarea" o "AWS" para acceder a su consola

    Privacidad

    Al acceder al lab de un estudiante, puedes ver toda su configuración. Úsalo solo para ayudar, no para corregir sin su conocimiento.

    Paso 16: Gestión de alumnos y acceso¶

    Objetivo: Saber cómo gestionar el acceso de los alumnos al Learner Lab.

    15.1. Desactivar acceso de un alumno¶

    Cuándo hacerlo: - Para "congelar" su trabajo al finalizar el plazo de entrega - Si está usando demasiados recursos - Si necesitas revisar su trabajo sin que haga cambios

    Cómo hacerlo: 1. Ve a "Personas" en el curso 2. Busca el estudiante 3. Haz clic en los tres puntos (...) junto al nombre 4. Selecciona "Desactivar" o "Deactivate" 5. El estudiante ya no podrá acceder al Learner Lab

    15.2. Reactivar acceso de un alumno¶

    1. Ve a "Personas"
    2. Busca el estudiante desactivado
    3. Haz clic en los tres puntos (...)
    4. Selecciona "Activar nuevamente al usuario" o "Reactivate user"

    16.3. Ver todos los labs activos¶

    1. Accede al Dashboard del Learner Lab: - Ve a "Asignaturas" → Selecciona el curso - "Contenidos" → Haz clic en el Learner Lab - Pestaña "Dashboard"
    2. Verás una lista de todos los estudiantes
    3. Los que tienen el LED verde tienen el lab activo
    4. Puedes ver quién está trabajando en tiempo real

    Información importante a recordar¶

    • Cada estudiante tiene $100 USD de crédito
    • El Learner Lab tiene tiempo limitado (normalmente 4 horas)
    • Los recursos se eliminan automáticamente al finalizar el tiempo del lab
    • Los labs de diferentes estudiantes son independientes
    • El NAT Gateway tiene coste ($0.045/hora aproximadamente)

    Solución de problemas comunes¶

    Problema: Creé el Learner Lab pero no lo veo en el Panel de control ni en Asignaturas¶

    Esto es completamente normal. El Learner Lab NO aparece en el Panel de control porque no es un curso, sino contenido dentro de un curso.

    Diagnóstico paso a paso:

    Paso 1: Verificar que estás en el lugar correcto 1. El Panel de control muestra cursos/asignaturas, no contenido 2. El Learner Lab está dentro de un curso, no es un curso en sí

    Paso 2: Acceder al curso 1. Haz clic en "Asignaturas" en el menú lateral izquierdo 2. Verás una lista de cursos (igual que en el Panel de control) 3. Haz clic en el curso donde creaste el Learner Lab 4. Esto te llevará dentro del curso

    Paso 3: Buscar dentro del curso

    Una vez dentro del curso, el Learner Lab puede estar en diferentes lugares:

    Lugar 1: En el menú lateral del curso - Busca en el menú lateral izquierdo opciones como: - "Inicio" o "Home" - "Módulos" o "Modules" - "Contenidos" o "Content" - "Páginas" o "Pages"

    Lugar 2: En las pestañas superiores - Puede haber pestañas en la parte superior: - "Módulos" - "Contenidos" - "Asignaciones" - Haz clic en "Módulos" primero

    Lugar 3: En la página principal del curso - A veces el contenido aparece directamente en la página de inicio del curso - Desplázate por la página buscando elementos relacionados con "Lab" o "AWS"

    Paso 4: Si no lo encuentras en ningún lugar

    1. Verificar que realmente se creó: - ¿Recuerdas haber visto un mensaje de confirmación al crearlo? - ¿Apareció algo nuevo en la pantalla cuando lo creaste? - Intenta crear el Learner Lab de nuevo siguiendo los pasos del Paso 4

    2. Buscar con Ctrl+F: - Una vez dentro del curso, presiona Ctrl+F (o Cmd+F en Mac) - Busca: "Learner", "Lab", "AWS", o el nombre que le pusiste - Esto buscará en toda la página

    3. Revisar todas las secciones del curso: - Haz clic en cada pestaña/sección del curso - Busca en: Módulos, Contenidos, Asignaciones, Páginas, etc.

    Si después de todo esto no lo encuentras:

    • Es posible que no se creó correctamente
    • Intenta crear el Learner Lab de nuevo (Paso 4)
    • O puede que necesites permisos especiales (contacta con administrador)

    Problema: No puedo crear el Learner Lab¶

    Posibles causas: - El Learner Lab no está disponible en tu cuenta - Necesitas permisos adicionales - Contacta con el administrador de AWS Academy

    Problema: Los alumnos no pueden iniciar el lab¶

    Solución: - Verifica que están matriculados en el curso - Verifica que aceptaron la invitación por email - Verifica que el Learner Lab es visible para estudiantes - Intenta iniciar el lab desde el Dashboard como instructor

    Problema: Los alumnos no tienen créditos¶

    Solución: - Verifica que cada estudiante tiene su propio Learner Lab - Los créditos son por estudiante, no compartidos - Si un estudiante usó todos sus créditos, no puede crear más recursos hasta que se reinicien

    Problema: No puedo acceder al Dashboard¶

    Solución: - Verifica que estás como instructor, no como estudiante - Intenta refrescar la página - Contacta con el administrador si persiste

    Notas finales¶

    Esta guía te proporciona todos los pasos necesarios para preparar las prácticas de AWS GameDay 2025 para tus alumnos. Recuerda:

    1. Prueba todo antes: Realiza una prueba completa antes de la sesión con alumnos
    2. Sé paciente: Los alumnos necesitarán más tiempo del estimado
    3. Usa el Dashboard: Es tu herramienta principal para ver el progreso y ayudar
    4. Enfatiza la limpieza: Recuerda a los alumnos eliminar recursos para ahorrar créditos
    5. Documenta problemas: Anota los problemas que encuentres para mejorar la próxima vez
